# env-input allowlist — deliberate env var reads in src/ production code.
#
# Policy: argv addresses; environment variables are handoff surfaces set
# for child processes by their parent, never inputs consulted by rwv itself.
# The inventory is $HOME and, on Windows, PATHEXT.
#
# Scope: this allowlist covers std::env::var and std::env::var_os reads
# in non-test production code under src/. The dirs crate reads $HOME via
# OS identity APIs (dirs::home_dir), not via std::env::var; it is excluded
# from this textual check and documented here. std::env::args and
# std::env::current_dir are argv and cwd respectively — out of scope.
#
# Format (one entry per line, blank lines and lines starting with '#' ignored):
#
#   env-input:<VAR_NAME>  # <reason>
#
# Every entry is a recorded decision. Entries stay until the named read
# is removed from src/ or promoted to a documented handoff surface.
# No age-based expiry — use structural triggers (name the removal change
# or the condition, not a date).

env-input:PATHEXT  # Windows' definition of executable, read as the `which` crate reads it for dispatch, so plugin discovery lists the verbs dispatch resolves; never a handoff surface
env-input:RWV_WORKSPACE  # read by the bundled rwv-each plugin, which is the child this handoff surface is set for; rwv itself never reads it
env-input:RWV_WORKWEAVE  # read by the bundled rwv-each plugin, which is the child this handoff surface is set for; rwv itself never reads it
env-input:RWV_WORKWEAVE_UNREGISTERED  # read by the bundled rwv-each plugin, which is the child this handoff surface is set for; rwv itself never reads it
env-input:RWV_TEST_PAUSE  # read only in a build with the test-pause cargo feature, which no release enables, to arm a pause point a test drives a race through; the shipped binary carries no read of it, which scripts/ci-local.sh's no-test-pause stage holds
env-input:RWV_TEST_PAUSE_TRACE  # read only in a build with the test-pause cargo feature, which no release enables, to append the name of each pause point a process passes to a file a test names; the shipped binary carries no read of it, which scripts/ci-local.sh's no-test-pause stage holds
env-input:RWV_TEST_WITHHOLD_UNDER  # read only in a build with the test-pause cargo feature, which no release enables, to narrow RWV_TEST_WITHHOLD to the publishes under one directory, so a test reaches a refusal on an operation's second directory; the shipped binary carries no read of it, which scripts/ci-local.sh's no-test-pause stage holds
env-input:RWV_TEST_WITHHOLD  # read only in a build with the test-pause cargo feature, which no release enables, to stand in a filesystem that lacks hard links or a no-replace rename, which no unprivileged test can mount; the shipped binary carries no read of it, which scripts/ci-local.sh's no-test-pause stage holds
env-input:RWV_PROJECT  # read by the bundled rwv-each plugin, which is the child this handoff surface is set for; rwv itself never reads it
